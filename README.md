# AI Agent System

🧠 Автономный AI агент с инструментами, построенный на архитектуре ReAct (Reasoning + Acting)

## 🚀 Возможности

### 🤖 Интеллектуальное взаимодействие
- **Архитектура ReAct** - рассуждение и действие в циклическом процессе
- **Контекстная память** - запоминание истории разговора
- **Автономное принятие решений** - выбор инструментов на основе анализа

### 🛠️ Инструменты агента

#### 🔢 Calculator
- Математические вычисления любой сложности
- Поддержка функций: тригонометрия, логарифмы, степени
- Безопасное выполнение выражений

#### 🌐 Web Search
- Поиск информации в интернете через DuckDuckGo
- Автоматическое использование прокси при необходимости
- Настройка количества результатов

#### 📁 File Operations
- Чтение, запись и управление файлами
- Безопасная работа в ограниченной директории `workspace`
- Просмотр содержимого директорий

#### 💻 System Info
- Мониторинг использования CPU, памяти, диска
- Информация о системе в реальном времени
